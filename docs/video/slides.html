Limits, and what's next

Today
  • Sepolia only, until block access lists reach mainnet.
  • Private lookup covers about 1,000 addresses.
  • Alerts need the app open, or Watch mode on a phone.
  • Copy trades are public once they land.
Next
  • A light client. Lodestar already serves the sync-committee data we need.
  • Faster PIR (SimplePIR or YPIR) for every active address.
  • Local quotes from verified pool state, so a quote names nothing.
  • A passkey wallet instead of a browser key.

All of it is in the README, with the numbers.
